권한 및 승인

일반 직원은 본인 업무만 조회합니다. 업무 상태 변경과 메일 전송을 포함한 쓰기 동작은 사용자 승인 이후 진행하는 설계를 시연합니다.

이 화면은 원본 LangGraph 실행 결과가 아닌, 같은 개념을 재현한 정적 목업입니다. 실제 권한 검증·API·메일 발송은 수행하지 않습니다.
